wailing_caverns_instance.blp and wailing_caverns_approach.blp:
Dungeon Maps parchment maps, painted procedurally (tools/parchment.py, tools/build_wailing_map.py)
from Blizzard's own Wailing Caverns minimap textures. Every passage keeps the client's coordinate
frame, so bosses, routes and the live arrow line up. Artwork/geometry derived from Blizzard's game
assets remains Blizzard Entertainment's. Placement data: Forever Dungeon Routes (MIT).
The instance map excludes the four approach-chamber textures. The approach map is painted from
the client's WailingCaverns.wmo minimap (WMO 109550 / ADT 36,33, placement cross-checked against
public HiddenMaps v1.2.2 metadata) in the frame of the Classic Atlas entrance map by Arith /
Atlas Team (GPL-2.0, ../LICENSE-Atlas.txt). The entrance key (A, B, Mad Magglish, Trigore,
Boahn) follows Atlas; no Atlas or HiddenMaps artwork or code is included. The red A->B line is
the shortest walkable path through that geometry. Registration notes:
validation/dungeons/wailingcaverns.
Turtle WoW's Atlas maps were reviewed as references; Turtle-only dungeon rooms/bosses were
not imported into the Forever map.
